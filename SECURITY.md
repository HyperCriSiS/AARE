# Security policy

AARE talks to a car's head unit, handles the phone's notifications and audio, and can show the
phone's screen in the car. Please report anything that could let someone else read, control or
impersonate any of that privately, not in a public issue.

## Reporting

Use GitHub's private vulnerability reporting: on this repository, **Security**, then
**Report a vulnerability**. Please include the version, the phone and Android version, the head
unit if one is involved, and the steps to reproduce.

A problem that also exists in upstream AARE is worth reporting to
[prototux/AARE](https://github.com/prototux/AARE) as well.

## Supported versions

Only the latest release gets fixes.
